# Reports

This folder contains generated or historical quality reports used by the real-input corpus workflow.

Keep small human-readable reports here when they are still referenced by scripts or fixture manifests. Large generated logs should only stay when they are active regression evidence; otherwise move them to `docs/archive/`.

Current active corpus defaults are owned by `scripts/vipin_corpus/cli.py` and `tests/fixtures/real_inputs/vipin_nordic_calculator_corpus_manifest.json`.
