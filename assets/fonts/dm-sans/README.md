# DM Sans

The Booknordics theme uses DM Sans. Download the Regular, Medium, SemiBold and Bold TTF files from the official Google Fonts distribution and place them in this folder using these names:

- `DMSans-Regular.ttf`
- `DMSans-Medium.ttf`
- `DMSans-SemiBold.ttf`
- `DMSans-Bold.ttf`

DM Sans is distributed under the SIL Open Font License 1.1. The font binaries are intentionally not committed by the patching environment.
